Database Relationship: This page displays deviation statistics stored in the same database as the "Mean Values" page.
  • Same Database: Both pages use the results table. Deleting an entry on "Mean Values" also removes it from this page.
  • Manual Calculation: Deviation statistics are NOT automatically calculated when entries are added/updated. Click "Calculate Statistics" to compute or update them.
  • Persistent Storage: Once calculated, statistics are saved in the database and persist across sessions.

The tool treats the "T_outdoor (WB)" column as wetbulb temperature. If entries show unrealistic deviations, this may indicate that the column contains relative humidity data instead, requiring manual data correction. Maximum deviations are shown in Kelvin (K) for temperature differences.

Filtering Help:
  • Numeric Filters: Use operators for deviation columns (Mean DB Dev, Mean WB Dev, Mean Tsup Dev, Mean Tmean Dev, etc.)
    • >1 = greater than 1
    • <5 = less than 5
    • >=2 = greater than or equal to 2
    • <=3 = less than or equal to 3
    • 0.5-2 = range between 0.5 and 2
    • =1.5 = exact value 1.5
    • !=2 = not equal to 2
  • Text Filters: Use wildcards for text columns (File Name, Test Condition, etc.)
    • * = any characters (e.g., HP*)
    • ? = single character (e.g., HP?)
    • =text or "text" = exact match
    • ^text = starts with
    • text$ = ends with
