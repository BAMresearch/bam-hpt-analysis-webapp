Input Text Column Data

Enter text values for your TEXT columns. You can paste data from Excel or type it manually.

Format: Each line should contain: File Name, Data Set, Start Time, End Time, Value
• You do NOT need to include a header row - just paste the data directly
• If you copy from Excel and it includes headers (like "File Name, Data Set..."), that's fine - it will be automatically skipped
• You can copy from Excel and paste here (tab or comma separated)
• You can also type manually, one entry per line
• Example (without header - recommended):
HPT_RRT2_Lab04_E.xlsx, 1, 10, 4000, E
HPT_RRT2_Lab04_E.xlsx, 2, 4010, 8000, E
 • Example (with header - also works):
File Name, Data Set, Start Time, End Time, test_cond

Calculate Derived Column

Use Python syntax, not Excel formulas! Use column names as variables. Examples:
• avg_heating_capacity_corr / avg_power_input_corr (division)
• avg_t_supply - avg_t_return_emu (subtraction)
• (avg_t_db + avg_t_wb) / 2 (average)
• "YES" if abs(column_name) > threshold_value else "NO" (conditional - Excel IF conversion)
• abs(column_name) (absolute value - Excel ABS conversion)
Note: Excel =IF(ABS(AT232)>$CC$1;"NO";"YES") becomes:
"NO" if abs(column_name) > threshold_value else "YES"
(Replace column_name with your actual column name and threshold_value with a number)

Calculate Time Series Analysis Column

Counts how many times the parameter exceeds the upper limit or falls below the lower limit.
Use df to refer to the time series DataFrame. Examples:
• (df['T_supply'] > 50).sum() - count values above 50
• df['T_supply'].std() - standard deviation
• ((df['T_supply'] - df['T_supply'].mean()).abs() > 2).sum() - count outliers
