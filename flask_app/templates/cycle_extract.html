Cycle Extraction

Load an Excel file to visualize time series. Click the plot to set start/end times. Use auto-suggestions, edit them, or define your own cycles. Existing DB entries are shown for comparison.

Suggest cycles uses uncorrected electric power (e.g. Electric Power Input (without correction) or Pel_el (uncorr)), finds compressor “off” boundaries, then merges nearby drop shoulders using Min gap. Min gap is not a minimum cycle length—it controls merging of timestamps that belong to the same electrical drop; set it shorter than typical pulse spacing if suggestions lump runs together or disappear.

Detector details (optional)
  • Sampling: on ~10 s grids, split mainly on sustained true-off stretches; on 1 Hz files, sustained off must be longer (linked to Min gap) so brief defrost-length dips don’t become their own cycles.
  • Start of file: if the trace clearly starts mid-pulse (high median power before the first long off), the incomplete leading block is skipped.
  • Fallback slopes: if off-based splitting isn’t enough, scan forward slopes (P[i]−P[i−1])/Δt on median-smoothed power; look ~40 s ahead for a minimum (“trough-ahead”). Effective drop = max(one step, P[i−1]−trough) so slow 1 Hz ramps are still detected.
  • Keep/reject: a candidate is kept only if power before the step is clearly “on” and either the trough sits in the file’s idle/off band or the pattern looks like staged shut-down (large cumulative drop vs a high-percentile load scale; trough below pre-plateau and nominal on). That filters most high→intermediate dips but keeps gradual ramps.
  • Min gap: merges nearby shoulder times from the same drop. Among slopes within ~8% of the steepest, the earliest shoulder wins (pure “steepest only” would pick the last step of a staircase). Starts are merged if raw power between them never reaches true idle/off (drops shallow standby wiggles).
  • Stored times: Start is the last plateau point before the drop (time[i−1]), nudged one median Δt earlier to line up with the raw chart; the previous cycle’s End is the last timestamp strictly before the next start (e.g. 2720 s vs 2730 s on a 10 s grid).
  • Tuning: if real cycles sit closer than Min gap, they may merge—reduce the gap. If Min gap ≫ shortest off/on spacing, neighbouring shoulders collapse and you may get few suggestions—use a gap well below pulse spacing.

The parent entry stays the full cycle. Edit clocks reads this file only and opens D (or S) + H, plus equilibrium / evaluation inside H on defrost and continuous cycles, so you can change them. It writes nothing: Save all clocks stores the file (or tick show on the rows you want), Save clocks stores one row. A power-transition time already on the row is reused, never overwritten; where it is still empty the same detector Apply uses fills the preview only. Rows whose kind stays unknown are skipped and listed. Lengths come from flask_app/config/cycle_periods.json. Period layers stay off until you turn them on. show is available for any row that already has saved clocks — no click needed — and for any row you have open in Edit clocks; ticked rows then draw D/S, H, equilibrium and evaluation on this chart. While you are editing a row the layers draw the clocks you have open, otherwise the saved bands — so a file you have just reloaded shows its stored clocks without re-deriving anything.
